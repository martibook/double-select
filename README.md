# double-select

A browser extension:

Select a context text as A, and select a part of it as B, ask LLM to explain B given the context of A, with the explanation displayed in a side pane.

![image](https://github.com/user-attachments/assets/630ba494-864e-45a5-abd4-23566eac31c3)


## Setup

Make a copy of `sample.config.json` and name it as `config.json`, fill in valid values for keys in it.
